# RikkaAI 今日升级内容

> 日期：2026-08-28  
> 范围：根据今日工作区中的代码、配置、测试和已有升级记录整理。  
> 说明：工作区包含部分此前未提交的 WIP；本文记录当前可见的升级内容，不代表一次提交的完整变更集。

## 一、今日概览

今天的升级主要集中在五个方向：

1. 强化 Agent 的工具调用、实时信息判断、主动性和情感状态。
2. 增加后台做梦、定时任务、个人数据摄入、成本记录等自主运行能力。
3. 完善记忆层，包括 Markdown 真源、标签、surprise 加权、gap analysis 和知识 wiki。
4. 增加 MCP、模型能力路由、工具输出压缩、写入校验和离线切换等扩展接口。
5. 改进桌面端聊天界面、语音合成反馈、主题背景和睡眠计算设置，并加强密钥保护。

## 二、核心能力升级

### 1. Agent 与对话链路

- `brain/agent.py` 支持流式回复中的多工具调用累积与执行。
- 工具调用可通过回调通知 GUI，界面能够显示“正在调用什么工具”。
- 工具执行结果写入成本/执行日志，并在回传模型前进行压缩，减少无效 token。
- system prompt 动态注入需求状态、精力、孤独感和 gap analysis 信息。
- 对“天气、实时信息、记忆回顾”等请求增加工具优先规则，降低凭训练数据猜测的风险。
- 保留非幂等工具的未知结果记录，避免副作用工具被无条件重复执行。

### 2. 情感与主动性

- `brain/needs.py`：建立社交、掌控、新奇、休息等需求，以及精力池和孤独感模型。
- `brain/planner.py`：根据需求、冷却时间、时间段和成功概率决定是否主动联系。
- `main_window.py` 的主动提示会注入需求状态和 planner 建议。
- 对话发生时更新需求状态，右侧 `EmotionStatusPanel` 可展示当前情绪和各项指标。
- 主动定时器继续由 `set_proactive_timer` 形成链式调度。

### 3. 后台自主运行

- `brain/dream.py`：后台合并记忆、消解冲突、更新画像、生成快照和 wiki。
- `brain/scheduler.py`：支持自然语言定时任务。
- `brain/autofetch.py`：扫描 inbox 并将个人数据摄入记忆。
- `brain/background.py`：统一启动做梦、自动拉取和定时服务，使用 daemon 线程。
- `main.py` 启动应用后拉起后台服务，各能力仍受特性开关控制。
- `brain/backup.py`：应用启动时自动备份核心数据库，并保留有限数量的近期备份。

## 三、记忆层升级

新增或完善的模块位于 `brain/memory/`：

| 模块 | 能力 | 当前状态 |
|---|---|---|
| `markdown_store.py` | 将记忆导出为可读、可 diff、可迁移的 Markdown 真源 | 已接入做梦流程 |
| `tags.py` | user / agent / app / project / session 正交标签 | 模块就绪，消费点待继续接入 |
| `surprise.py` | 对意外程度和情绪价值高的记忆加权 | 已接入做梦流程 |
| `gap.py` | 分析某主题“还不知道什么” | 已注入 Agent prompt |
| `wiki.py` | 将高价值记忆整理为可编辑知识页 | 已接入做梦流程 |

同时保留 SQLite、文件系统、全文检索、图谱和向量记忆等原有存储能力。

## 四、工具、联网与模型能力

- `brain/mcp_client.py`：接入外部 MCP 工具，带缓存、上限和优雅降级。
- `brain/model_routing.py`：为 chat、vision、image、asr、tts、embedding 预留按能力路由。
- `brain/compressor.py`：压缩工具输出后再发送给模型。
- `brain/verify.py`：为 Python AST、JSON、Node 等写入内容提供确定性校验接口。
- `brain/netsentinel.py`：断网时提供本地模型 fallback 和待重放队列接口。
- `brain/tools.py`：
  - 使用 `trust_env=False` 的 HTTP session，普通请求不读取系统代理。
  - SearXNG 不可用或无结果时切换 Argo，并向上层说明切换原因。
  - 天气工具支持当前天气和未来几天信息。
  - 天气、图片、GitHub、B 站、YouTube、RSS、Twitter 等场景提供专用工具路由提示。

## 五、安全与配置

- 新增 `secret_store.py`：优先读取环境变量；Windows 下使用当前用户 Credential Manager 保存密钥，缺少可选依赖时有原生 API fallback。
- 新增 `migrate_secrets.py`：将配置文件中的明文 API Key 迁移到安全存储，并保留迁移前备份。
- 配置文件改为保存模型、地址和 `secret_ref`，不再要求把 Key 写入 JSON 或源码。
- README 增加密钥安全说明和受控 E2E 测试说明。
- `privacy_mode_enabled` 预留为“推理不出机”开关，默认关闭。
- `config.py` 集中管理升级开关；`brain/features.py` 负责统一读取和持久化。

## 六、桌面端与语音界面

- `EmotionStatusPanel`：聊天页右侧情感状态卡，展示情绪、精力、好感度、社交需求等指标。
- `ChatWidget`：增加语音合成中的进度气泡、流式气泡生命周期管理和工具执行提示。
- `main_window.py`：连接语音合成开始/完成信号，并将工具调用事件反馈到聊天区。
- `ChatBackgroundPage`：支持聊天页背景图按窗口比例铺满，并保留主题洗色层。
- `sleep_compute_settings.py`：扩展睡眠计算/后台计算设置、自定义模型方案和相关视觉资源。
- 聊天页主题和玻璃效果曾做过一轮试验；根据要求已回退，当前不包含那轮临时玻璃样式修改。

## 七、特性开关

默认开关定义在 `config.py` 的 `UPGRADE_FLAGS_DEFAULTS`，可通过 `memory_data/user_config.json` 覆盖，也可以使用：

```python
from brain import features

features.set_flags({"mcp_enabled": False})
```

### 默认开启或已接入

`costlog_enabled`、`memory_gap_analysis_enabled`、`emotion_needs_enabled`、`decision_planner_enabled`、`tool_compress_enabled`、`dream_enabled`、`cron_enabled`、`autofetch_enabled`、`mcp_enabled`、`memory_markdown_enabled`、`memory_surprise_weight_enabled`、`memory_wiki_enabled`。

### 模块已就绪但仍需消费点

`memory_orthogonal_tags_enabled`、`per_model_routing_enabled`、`verify_enabled`、`netsentinel_enabled`。

### 默认关闭

`split_reply_enabled`：分段发送能力保留，但默认关闭。  
`privacy_mode_enabled`：隐私模式预留，默认关闭。

## 九、当前注意事项

1. 工作区存在大量未提交修改和测试生成的临时目录；本文只记录功能，不代表这些文件都应提交。
2. `mcp_enabled` 虽默认开启，但只有配置 MCP 服务时才会实际提供外部工具。
3. 模型能力路由、确定性写入校验和离线切换目前主要是独立模块或挂点，仍建议逐个接入并做真实环境验证。
4. 后台做梦、定时和自动拉取会产生后台任务，正式使用前应检查对应开关和间隔设置。
5. 启动时会尝试备份数据库；应确认备份目录具有足够磁盘空间。
